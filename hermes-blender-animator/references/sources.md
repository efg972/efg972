# Sources the Blender Animator may learn from

Order of trust: official docs, then Blender Foundation material, then established educators. Verify the Blender version of any tutorial.

## Official
- Blender Manual: https://docs.blender.org/manual/en/latest/ (animation: `animation/`, rigging: `animation/armatures/`)
- Python API reference: https://docs.blender.org/api/current/
- Blender Studio training and open movie rigs: https://studio.blender.org/
- Blender Developer docs (release notes, API changes): https://developer.blender.org/docs/release_notes/

## Educators (to be re-checked by the agent, not guaranteed current)
- Blender Guru, CG Cookie, Grant Abbitt, Ducky 3D, Polyfjord, Blender Studio courses
- YouTube transcripts: use the youtube skill/MCP to fetch transcripts, then summarize into notes.

## Reference for craft
- The Animator's Survival Kit (Richard Williams), 12 principles of animation (Disney).

## Rules
- Record URL, Blender version, and date for every note.
- If two sources conflict, test in Blender and prefer the manual.
